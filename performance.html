Applied Performance Optimizations

  • Flexbox Layout Architecture: Used lightweight CSS Flexbox (`display: flex; flex-wrap: wrap;`) for dynamic, responsive book cards without excessive CSS frameworks.
  • Lazy Loading Images: Added `loading="lazy"` to image elements to delay image fetching until elements scroll into the viewport.
  • Compressed SVG Vector Assets: Utilized ultra-lightweight vector covers eliminating heavy PNG/JPG downloads.
  • Lazy Loading Video: Used `preload="none"` and `loading="lazy"` on the video container to prevent initial page load bandwidth consumption.
  • CLS Prevention: Specified explicit `width` and `height` attributes on image and video wrappers to reserve layout space and eliminate Cumulative Layout Shift.
  • Zero Render-Blocking Scripts: Built strictly with pure semantic HTML and vanilla CSS to achieve maximum PageSpeed Insights score.
